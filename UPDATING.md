# Updating Everything

There are two independent things to keep current: **code** (versioned in git, mirrored
across two repos) and **data** (the SQLite DB, embeddings, and entity tables — *not*
in git, regenerated by scripts and backed up separately).

---

## 1. Update the CODE (both repos)

Whenever scripts or UI files change, commit and push to **both** repos. The two share
identical `scripts/` (origin) ↔ `automaton/scripts/` (monorepo).

```powershell
# --- Origin ---
cd "D:\Sanksrit Automatons\sanskrit-automatonv2"
git add scripts\*.py scripts\*.html README.md UPDATING.md
git commit -m "update: <what changed>"
git push origin main
git status -sb        # expect: ## main...origin/main  (no ahead/behind)

# --- Monorepo mirror ---
cd "D:\sanskrit-symphony"
git add automaton\scripts\*.py automaton\scripts\*.html automaton\README.md automaton\UPDATING.md
git commit -m "sync: <what changed>"
git push origin main
git status -sb
```

Keep the two `scripts/` folders identical. To copy the origin's scripts into the
monorepo before committing:

```powershell
Copy-Item "D:\Sanksrit Automatons\sanskrit-automatonv2\scripts\*" `
          "D:\sanskrit-symphony\automaton\scripts\" -Force
```

**If git says `index.lock` exists** (a crashed editor/maintenance left it):

```powershell
Get-Process git -ErrorAction SilentlyContinue          # should print nothing
Remove-Item "D:\Sanksrit Automatons\sanskrit-automatonv2\.git\index.lock" -Force -ErrorAction SilentlyContinue
Remove-Item "D:\sanskrit-symphony\.git\index.lock" -Force -ErrorAction SilentlyContinue
# then re-run the add/commit/push
```

The `LF will be replaced by CRLF` warnings are harmless (Windows line-ending
normalization) — nothing to fix.

## 2. Update the DATA (regenerate + back up)

Run these when the dashboard and all jobs are **idle** (writers; the DB is on a
Drive-synced disk). Every one is idempotent and resumable — safe to re-run.

### a. New translations

Translate new/pending verses, then heal weak ones:

```powershell
cd "D:\Sanksrit Automatons\sanskrit-automatonv2"
python scripts\translate_both.py --db data\context.db --doc <code> --engine gemini:gemini-2.5-pro
python scripts\qa_scan.py   --db data\context.db --lang en --write
python scripts\heal_lowqa.py --db data\context.db --doc <code> --engine gemini:gemini-2.5-pro --below-qa 0.2
```

### b. Refresh the semantic index (after new translations)

```powershell
python scripts\build_embeddings.py --db data\context.db      # embeds only new/changed verses
```

### c. Refresh the entity layer (after new translations)

```powershell
python scripts\extract_entities.py --db data\context.db --retry-empty
```

`--retry-empty` also re-processes any verse a prior parse failure left empty. To redo a
single text from scratch: `--doc <code> --refresh`.

### d. Back up the database (do this after a data update)

```powershell
python scripts\db_backup.py "data\context.db" "D:\backups\context_$(Get-Date -Format yyyyMMdd).db"
```

`db_backup.py` verifies source health and copy integrity and refuses to copy a locked
or corrupt DB.

## 3. One-shot "update everything" sequence

Idle the dashboard/jobs, then:

```powershell
cd "D:\Sanksrit Automatons\sanskrit-automatonv2"

# DATA: translations (per doc as needed) → embeddings → entities → backup
python scripts\build_embeddings.py --db data\context.db
python scripts\extract_entities.py --db data\context.db --retry-empty
python scripts\db_backup.py "data\context.db" "D:\backups\context_$(Get-Date -Format yyyyMMdd).db"

# CODE: commit + push both repos
git add scripts\*.py scripts\*.html README.md UPDATING.md
git commit -m "update: refresh scripts + docs"
git push origin main
Copy-Item ".\scripts\*" "D:\sanskrit-symphony\automaton\scripts\" -Force
Copy-Item ".\README.md",".\UPDATING.md" "D:\sanskrit-symphony\automaton\" -Force
cd "D:\sanskrit-symphony"
git add automaton\scripts\*.py automaton\scripts\*.html automaton\README.md automaton\UPDATING.md
git commit -m "sync: refresh scripts + docs"
git push origin main
```

## 4. Verify state

```powershell
# code: both should read "## main...origin/main" with nothing pending
cd "D:\Sanksrit Automatons\sanskrit-automatonv2"; git status -sb
cd "D:\sanskrit-symphony"; git status -sb

# data: coverage snapshot (read-only)
cd "D:\Sanksrit Automatons\sanskrit-automatonv2"
python scripts\qa_report.py --db data\context.db --coverage --all
```

Entity / embedding counts (in Datasette, or DB Browser):

```sql
SELECT (SELECT COUNT(*) FROM passage_embeddings) AS vectors,
       (SELECT COUNT(*) FROM entities)          AS entities,
       (SELECT COUNT(*) FROM entity_mentions)   AS mentions;
```
