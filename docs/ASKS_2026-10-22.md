# Our asks, and where each stands (22 Oct 2026, evening) (DOCS88_2026_10_22)

The one place where each ask stands, under a key that does not change. The asks were spread over the documentation
patches DOCS2 to DOCS88, and the ENTERPRISE_PATH's labels are reused from addendum to addendum: `scripts\doc_register.py` reads its
471 rows as 329 items under 200 labels, and 63 labels name more than one item (S1 eight, S2 seven, R1 seven). So
"the state of S1" has no single meaning. From DOCS88 on, a new ENTERPRISE_PATH row cites a key of this file.

How to read the states: **Done** (with the release or the run that did it), **Yours** (a decision or a click only you
can make), **Next** (free, for the next round), **Money** (needs the cap; the amount is the estimate recorded),
**Waiting** (on someone outside). Figures are as recorded on the date given; the dashboard's Usage tab has the live
spend.
