## ✅ Recommended path (minimal + clean)

1. **Keep your OCR as-is.**
   You’ve already got `data/raw/panchatantra_XXXX.jsonl` and rows in `passages`. The ingest script is fine for new pages. 

2. **Light-clean only the noisy pages, then overwrite those pages in DB.**
   This removes ZW chars, normalizes, and drops digit-only lines (great for page-number noise):

   ```powershell
   # choose a clean output folder
   python .\scripts\post_normalize_ocr.py --in data\raw --out data\clean --glob "panchatantra_*.jsonl"

   # overwrite DB text for all pages from the cleaned files
   python .\scripts\ingest_jsonl_fast.py --doc panchatantra --glob "data\clean\panchatantra_*.jsonl"
   ```

   (You can also run only for the 5 weak pages by specifying those filenames.)  

3. **Backfill English translations only where missing.**
   Use the translator that skips headings/TOC/junk automatically:

   ```powershell
   python .\scripts\translate_passages.py --doc panchatantra --since-page 1 --until-page 9999 --sleep 0.6
   ```

   (It calls the MT engine under the hood; make sure `OPENAI_API_KEY` is set.)  

---

## 🧭 When to use each script (and why)

* **`ingest_pdf.py`** – Use for **new PDFs** you drop into `inbox/`. It does OCR → sentence split → normalize → (optionally) MT and writes to DB. Honor envs like `TESS_LANGS`, `SA_OCR_DPI`. For your next book, keep `TESS_LANGS=san` and (if needed) `SA_OCR_DPI=400`. 
* **`post_normalize_ocr.py`** – Best post-OCR cleanup: NFC, strip zero-width/PUA, unify danda/hyphen, **drop digit-only lines**. Use this on raw JSONL before re-ingesting those pages. 
* **`ingest_jsonl_fast.py`** – Fast **DB overwrite/upsert** of page text (and translation if present) from cleaned JSONL; perfect for fixing a handful of pages without rerunning OCR. 
* **`translate_passages.py`** – Preferred **backfill** for missing translations; skips headings/very low-Devanagari noise and pages you specify by range. 
* **`infer_mt.py`** – The translator itself (called by the above); it **skips junk/headings** and uses your `SA_GPT_MODEL`. You usually don’t run this directly. 
* **`norm_pass.py`** – Older/simpler normalizer (NFC, danda→`|`, hyphen unify). Use `post_normalize_ocr.py` instead unless you specifically want this lighter pass. 
* **`backfill_missing.py`** – Legacy backfill example that’s **hard-coded to `DOC="MBh-01"`**; prefer `translate_passages.py` where you can pass `--doc panchatantra`.
